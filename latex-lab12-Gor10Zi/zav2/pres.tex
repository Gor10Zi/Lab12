\section{Трикутник}

\begin{frame}{Що таке трикутник?}
Трикутник — це геометрична фігура, яка має:
\begin{itemize}
    \item 3 сторони
    \item 3 вершини
    \item 3 кути
\end{itemize}
\end{frame}

% 7. ПІФАГОР
\begin{frame}{Теорема Піфагора}

\begin{columns}

\begin{column}{0.5\textwidth}
Для прямокутного трикутника:

\[a^2 + b^2 = c^2\]

\begin{itemize}
    \item $a, b$ — катети
    \item $c$ — гіпотенуза
\end{itemize}

\vspace{0.3cm}

\textbf{Приклад:}
\[3^2 + 4^2 = 5^2\]

\[9 + 16 = 25\]

\end{column}
